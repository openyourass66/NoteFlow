# 本地主旋律重构验证记录

日期：2026-11-13。平台：Windows x64，RTX 4060 Laptop 8 GB，内存 16 GB，Python 3.11。

## 本轮交付

保留现有桌面、媒体解码、音符编辑、项目保存和音源合成，替换识别调度、主旋律解码和演奏时间规则。旧目录包保留，新的构建目录为 `dist/rebuild/NoteFlow`。不需要删除整个项目。

| 问题 | 当前处理 |
| --- | --- |
| 乐器 BGM 被自动转去识别人声 | 导入后明确选择乐器／人声；默认乐器走原曲、人声先分离。分轨试听不改变目标 |
| 复调候选混进输出 | Basic Pitch 生成候选，连续路径选择单一主旋律和休止；无可靠结果就提示，不回退成全体候选 |
| 瞬时低音拉低主旋律八度 | 混音中的神经 F0 必须与整段候选旋律一致才增强证据；不按单帧最响音认定主角 |
| 短暂漏检割断长音 | 仅在同音、能量支持、无新起音的短间隙中补接；真实静音保留 |
| 鼓点导致同音反复误切 | 模型起音还需对应音高及谐波的声学起音支持；持续音不因低音／鼓点独立起音而重复敲击 |
| 简谱和旋律两个播放版本 | 统一「演奏」，MIDI／WAV 保留秒级音符时间；节奏和调号校准用于排谱 |
| 难以试听比较 | 原曲、分轨、演奏切换保留位置；弱证据音符显示「待复核」 |
| 本地 GPU 无法使用 | 独立 PyTorch CUDA 环境，Demucs 与 torchcrepe 自动选 GPU；主程序保留 ONNX CPU |

简谱是同一旋律的显示形式。谱面暂时按固定 4/4 拍、恒定速度和十六分音符网格显示；演奏直接读取原始／编辑后的音符时刻，避免量化造成的停顿。没有通过混响、随机偏移或统一拉长音符来掩盖错误。

新项目格式版本为 2，保存提取目标、音域、选源方式及待复核区间；保留版本 1 的读取。命令行与桌面共用 `run_pipeline`。GPU worker 单独运行，支持取消和超时，未把 PyTorch 塞入桌面可执行文件。

## 实际验证

- 完整回归：59 项通过，4 条依赖弃用警告。覆盖媒体错误、中文路径、快速旋律、伴奏中的休止、真实重复音、八度跳进、低音干扰、取消、项目迁移、编辑、试听和导出。
- NVIDIA F0：22 秒带已知音高的合成谐波信号，中位误差约 0.70 音分，95 分位约 1.64 音分；20 秒分块交界最大误差约 0.78 音分。只证明该合成样本的音高与分块行为，不代表混音准确率。
- NVIDIA 分离：8 秒真实 BGM 片段约 5.12 秒完成；人声和伴奏均为 44.1 kHz 双声道、352800 帧，与原片段严格对齐。这项检查不评价分离质量。
- 界面：Windows 原生字体下检查 1000×680 和 1220×820 窗口；谱面、工具栏和播放器可见。修复切换音轨后再次拖动进度跳回起点的问题。
- Windows 目录包：构建通过；实际启动可执行文件、恢复最新样例项目、正常退出均通过；包内音高 worker 与验证过的源码一致。

## 复现

先按 README 安装桌面与可选推理环境，并配置 FFmpeg、FluidSynth 和 SF2。以下 PowerShell 命令在仓库根目录执行，示例媒体路径替换为实际文件：

```powershell
& .venv-m0\Scripts\python.exe -m pytest -q
& .venv-m0\Scripts\python.exe poc\check_pitch_worker.py `
    --python .tools\inference\Scripts\python.exe --output .poc-output\pitch-check
& .venv-m0\Scripts\python.exe poc\compare_rebuild.py 'C:\Music\example.mp3' `
    --output .poc-output\comparison
& .venv-m0\Scripts\python.exe -m PyInstaller --noconfirm `
    --distpath dist/rebuild --workpath build/rebuild packaging/noteflow.spec
```

`compare_rebuild.py --without-pitch` 可对照不使用神经 F0 的结果。测试需要 FFmpeg 与 ffprobe 位于 PATH，桌面与对比脚本也会查找 `.tools`。性能数字为本机单次运行，不是跨机器性能保证。

## 仍需验证或继续实现

当前是本地重构首版，没有把方案中的所有研究项称为完成。复杂同音色多声部、合唱、主旋律交接、长时间八度误判仍可能出错，需要增加真实素材标注和分段听测。尚未交付：目标乐器专用分离、局部候选 A/B 选择、三连音与变速拍图、整首超过 120 秒处理、选段循环与音量匹配，以及云端推理。

用户已明确先完善本地效果；当前没有云服务地址，不创建云端部署。后续质量判断以主旋律选对、音高与起止误差、主观可辨识度为依据，不以音符更多或声音更长作为验收标准。
